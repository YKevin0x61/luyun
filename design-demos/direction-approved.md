## 每版一句话

- **方向一 · 仪表台**：Dieter Rams / Braun 控制面板。40px 状态条 + 72px 图标轨 + 1px 发丝线分格 + 零圆角零阴影，橙只给要动手的三处。胆量点 = 顶部贯穿全屏的出餐速率尺。
- **方向二 · 作业流**：7shifts 一类排班产品。中列一张 220px 主卡回答「现在该干什么」，其余压成行卡；手机是第一形态。胆量点 = 只有请假配得上大卡和唯一那条实心按钮。
- **方向三 · 招牌墙**：香港街招。实色块 + 2px 奶白边 + 4px 硬投影 + 竖排域标签，招牌压边 9px。胆量点 = 导航本身是一面招牌墙。

## 体检结果

- 三方向四页全部 `console clean`（Playwright，1440×900）。
- `design_lint check`（内联副本，因为 React+Babel 的 .jsx 在 file:// 下被 CORS 拦，直接跑 html 必红——这是工具环境限制，不是页面错误）：
  - dir-1：0 红，2 黄（「·」8 处是店名/工作区/检查项的命名习惯；06/08/09 是时间刻度不是序号）
  - dir-2：0 红 0 黄
  - dir-3：0 红 0 黄
- `design_lint compare`：dir-1 ↔ dir-2 色板距离 0.017，判「撞色板」。判断：用户明确要求「深色为主、不做大面积浅色底」，三版只能在深色域内选色，色板距离必然小；但两版骨架完全不同（仪表网格 vs 卡片流），dir-3 是中明度青蓝底。**判为工具口径下的必然结果，不算三种皮。**
- 对比度：自己写了 `tools/contrast.py` 逐页扫低对比文本。dir-1 修掉了橙底白字（改纯黑字）、三级灰提亮到 #8D9389；dir-2 增加了 `--danger-ink` 过 4.5；dir-3 复扫 0 处。剩余命中均为半透明底（检测器把 rgba 当不透明）与色条上的深字，肉眼复核可读。

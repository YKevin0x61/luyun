# 厨务管家重做 · 六候选 → 三方向

共同输入：[spec.md](./spec.md)。每个候选先说「这套逻辑来自哪里」，再说「借的具体规则」。

## 候选 1 · 仪表台｜Dieter Rams 的 Braun 控制面板

**逻辑与来源**：最佳设计师（克制 · 西方）。Dieter Rams 在 Braun 时期的控制面板语言——刻度、状态灯、单一信号色、精确网格、无装饰的功能分区。选他的理由：用户重做的核心痛点之一是「这是后台不是设备」，而厨房里的一切都是设备（烤箱、和面机、油温表）。把管理后台当仪表处理，比当网页处理更贴题材。

**借的是什么**

1. 黑底 + 米白刻度字，**唯一信号色**（Braun 橙 #C8551F）只给「需要行动」的东西：逾期、待批、超标。
2. 面板之间用 1px 发丝线分区，**不用卡片阴影**；圆角 0–4px。
3. 数字用紧凑 grot + 等宽小数，标签小号但字距拉开（0.12em）——不是把小字塞满。
4. 可调项像旋钮一样带刻度：进度条、时间轴、出餐速率尺都要有刻度标记。

**主角素材**：数据图像——程序化 SVG 刻度尺与速率环，零图片依赖（T0 档）。

**骨架**：桌面 = 40px 顶部状态条 + 72px 左侧图标工具轨 + 主区 4 列仪表网格（KPI / 速率尺 / 待办 / 班次表）。手机 = 顶栏 + 单列仪表 + 底部 4 键。

**胆量花在哪**：顶部一条贯穿全屏的「出餐速率刻度尺」——每 15 分钟一格，当前时刻一根红针，峰值与最慢档口直接标在尺上。整页最贵的东西是这条尺。

**form 来自内容的哪里**：餐饮是按时间切片的生产系统（营业日 06:00 切、忙闲按 15 分钟计），刻度尺就是它本来的形状。

**配色推导**：从 Braun 仪器面板采样 → 收敛到炭黑 #14150F / 面板 #1B1D18 / 线 #2B2E28 / 字 #EDEBE3 / 次 #9CA095 / 信号橙 #C8551F / 通过绿 #6E9E7E。

**字体**：Inter Tight（拉丁/数字）+ 系统中文（PingFang SC）；数字用 tabular-nums。

## 候选 2 · 一个字｜佐藤可士和的品牌符号法

**逻辑与来源**：最佳设计师（大胆 · 东亚）。佐藤可士和为优衣库做的重塑：一个红色方块、白色粗体字、极少的颜色。方法不是「做得花」，是**一个压倒性的符号 + 其余全部安静**。

**借的是什么**

1. 一个满幅纯色面板（朱红 #D8361F）只放一件事：今天的营业额，数字 140px。
2. 其余区域深墨底（#171512），信息排成极简两列，行间用空格分区、不用线。
3. 全站最多三色：墨、朱红、米白。
4. 巨号与极小标签的极端反差（140px 数字 vs 13px 字幕，字幕拉字距）。

**主角素材**：巨字 + 纯色块，程序化（T0）。

**骨架**：桌面 = 左右 38/62 分栏，左侧整块朱红「今日」面板，右侧三行信息区。手机 = 上 42% 朱红数字面板，下 58% 卡片列表。

**胆量花在哪**：一整屏只有 5 个元素，最大的那个数字占掉 1/5 屏。

**form 来自内容的哪里**：单店老板每天只关心一个数——今天赚了多少；这个数字值得占掉一整面墙。

**配色推导**：从月份牌/日式包装的朱红采样 → 收敛到 #171512 / #D8361F / #F2EDE3 / 芥黄 #E8C24A 仅用于「待批」角标。

**字体**：Noto Sans SC 900（巨数字/主标）+ 系统中文（正文）；拉丁用 Archivo 800。

## 候选 3 · 作业流｜7shifts / Homebase 的排班产品

**逻辑与来源**：现实参照（同行业）。7shifts 是餐饮排班 SaaS，把「店长排班 + 员工看班」做成手机优先的产品（官网营销页已亲眼看：`refs/7shifts-home.png`——粗黑标题、橙色短下划线、极紧字距、圆角大按钮；**产品内页本次没看到**，卡片流这条规则是按餐饮排班品类的常见解法推演，标注不假装看过）。

**借的是什么**

1. 手机端**一张卡一件事**：卡高约 180–220px，卡内只有「谁 / 什么时候 / 要做什么 / 一个按钮」。
2. 顶部日期带：横向 7 天，今天的那个是实心圆角块。
3. 状态用 pill（待批 / 已通过 / 逾期），pill 里的字比正文小 1px 但加粗。
4. 底部 4 项 tab，选中项是实心图标 + 文字，未选中是线框图标。
5. 品牌层从 7shifts 官网实测的：标题字距收紧到 -0.03em、用一条 3px 短下划线（橙）在标题下方作强调，而不是装饰条。

**主角素材**：真实业务内容（班次、人、时间），不需要图片。

**骨架**：手机 = 日期带 → 主卡（下一件事）→ 列表卡 → 底部 tab。桌面 = 左侧域导航 224px + 中列卡片 + 右侧当日详情 360px。

**胆量花在哪**：把「今天」压缩成一件事——店长打开先看到「现在最该处理的那一件」，其余收在下面。

**form 来自内容的哪里**：店长每天在手机与电脑之间来回切，产品必须能在 30 秒内回答「我现在该干什么」。

**配色推导**：从 7shifts 的清爽卡片流采样 → 收敛到深色版：底 #0E1110 / 卡 #171C1A / 线 #232A27 / 字 #E8EEEA / 次 #92A39B / 主色薄荷 #2FB98A + 暖橙 #E08B3C 做提醒。

**字体**：系统中文 + Inter。

## 候选 4 · 按钮优先｜Toast POS 的作业界面

**逻辑与来源**：现实参照（同行业 · 作业面）。餐饮 POS 的界面约束是最狠的：油手、水手、强光、站着用。**Toast 官网被 Cloudflare 拦截，未亲眼看到产品界面**；已亲眼看到的是 Linear 的产品界面（`refs/linear-home.png`：暗底、侧栏 + 主区、极紧字距、发丝线、单色图标、无彩色强调）。所以这条候选借的是「POS 作业面的大按钮约束（推演）+ Linear 的暗色排版纪律（已看）」。

**借的是什么**

1. 主操作是**整条色块按钮**（高 52–56px），不是文字链。
2. 数字（金额、时间、数量）比标签大 2–3 倍，等宽对齐。
3. 面板靠底色层级分区（底 / 面板 / 高亮块），1px 发丝线只用在表格行。
4. 极紧的标题字距（-0.02em）、图标单色线性、不用彩色图标。

**主角素材**：色块与数字，程序化。

**骨架**：手机 = 顶部状态条 + 2 列大按钮网格 + 底部操作条。桌面 = 左列订单/任务 + 中间内容 + 右列操作。

**胆量花在哪**：验收页的「通过 / 驳回」做成两块各占半屏宽的 64px 高色块，图上不加任何小热区。

**form 来自内容的哪里**：后厨验收时手上是湿的、戴手套，按钮必须大得像物理按键。

**配色推导**：从 Toast 的 POS 深色皮肤采样 → 收敛到 #101211 底 / #1C211E 面板 / #F0F2EE 字 / 主色亮绿 #37C08A / 危险 #E2503F / 提醒 #E6A23C。

**字体**：系统中文 + Inter，数字用 tabular-nums。

## 候选 5 · 终端核｜秒数轮盘 web #16 Terminal-Core Soft-Futurism

**逻辑与来源**：秒数轮盘（web 分区 20 种，`53 % 20 + 1 = 14` 抽到「斜切流体渐变带」，但用户明确不要紫/靛渐变，顺延 15 又是浅色为主，再顺延到 **16 号 终端核软未来**，兼容）。炭黑 + 暖白 + 等宽字做骨架 + 工业极简 + 2.5D 等距小方块。样张：`assets/style-specimens/web/16-terminal-core.jpg`。

**借的是什么**

1. 等宽字贯穿**所有数字与标签**，正文用无衬线——排版反差就是质感。
2. 面板标题带一个小符号（`▸` 或 `//`），分区靠 1px 虚线。
3. 状态用方括号 `[ 在线 ]` `[ 待批 2 ]` 的写法。
4. 图标用 2.5D 等距方块（CSS transform 或 SVG），不用线性图标。

**主角素材**：等宽排版本身 + 等距方块图（程序化，T0）。

**骨架**：桌面 = 一行 40px monospace 状态行（店名 · 营业日 · 连接 · 时延 · 身份）+ 主区 bento 网格，块标题 monospace。手机 = 单列，顶部 monospace 状态行 + 块列表 + 底部 tab。

**胆量花在哪**：全站数字与标签都是等宽字，包括营业额——像一台厨房里的终端机打印出来的。

**form 来自内容的哪里**：后厨的配方、称重、计时都是精确数；系统本来就是给「读数」用的。

**配色推导**：从样张采样 → 炭黑 #0B0D14 / 暖白 #F2F0EF / 线 #23262E / 次 #8B9099 / 主色暖橙 #E2743A（不用样张的蓝紫渐变，改成单色）。

**字体**：ui-monospace（SF Mono / JetBrains Mono 兜底）+ 系统中文。

## 候选 6 · 招牌墙｜秒数轮盘 east #6 香港街招与招牌

**逻辑与来源**：秒数轮盘（east 分区 12 种，`53 % 12 + 1 = 6` 抽到 **香港街招与招牌**）。深夜墙面的招牌：高饱和纯色底 + 奶白边框 + 粗黑字 + 竖排 + 硬投影 + 外发光。样张：`assets/style-specimens/east/06-hk-street-signs.jpg`。

**借的是什么**（只借三件，不把整页做成街景）

1. 每一块信息都是一个「招牌」：实色块 + 2px 奶白描边 + 4px 硬投影（不用柔和阴影）。
2. 域标签用**竖排**（writing-mode: vertical-rl）贴在窄条上。
3. 层叠：招牌之间互相压边 8–12px，形成密集墙面；主操作是招牌上的一块红章。

**主角素材**：色块 + 粗黑汉字，程序化（T0）。

**骨架**：手机 = 竖排招牌堆叠（待批 / 待验收 / 整改各一块招牌），底部 tab 做成招牌条。桌面 = 左侧竖排名牌导航 + 主区招牌块网格。

**胆量花在哪**：导航本身是一面招牌墙，不是一个菜单。

**form 来自内容的哪里**：店里本身就是一条街的招牌（工作区、档口、岗位都贴着牌子），系统的信息块就长成招牌。

**配色推导**：从样张采样 → 夜蓝 #0B3A46 / 红 #C8322A / 黄 #E8B12E / 奶白 #F6EFE2 / 绿 #2E7D5B / 黑 #101010。

**字体**：Noto Sans SC 900（招牌主标）+ 系统中文（正文）。

## 六张缩略图与三条完整版怎么挑

缩略图：`thumbs.html`（六格 480×300，全画 P1「今天」桌面首屏）。

挑三条完整版的标准（按顺序）：单看够好 → 三张彼此不一样 → 不撞外观账本（账本为空，不限）→ 不用力过头。

**选出**：

| 方向 | 候选 | 理由 |
|---|---|---|
| **方向一 · 仪表台** | 候选 1（Rams） | 题材最贴（厨房设备语义）；克制、信息密度高，能扛住 39 页 |
| **方向二 · 作业流** | 候选 3（7shifts） | 同行业真实参照，最能落地成产品；手机端最强 |
| **方向三 · 招牌墙** | 候选 6（香港街招） | 差异最大的一极，回应「品牌气质重来」；只借三件事，避免用力过头 |

**备选（也在缩略图里给出）**：候选 2（佐藤符号，极简巨字）、候选 4（Toast 按钮优先）、候选 5（终端核，等宽排版）。看中哪张可以换上来做完整版。
